About downloads

You can download a video's thumbnail here — the still image shown with the result — as a JPG file. That's an image, not the video.

Downloading the video itself isn't offered: YouTube doesn't provide third-party websites a permitted way to download videos, and its terms don't allow it. Tools that promise otherwise are breaking those terms.

Want a video offline? YouTube's own app offers downloads on eligible videos for the uploader's audience, and creators can save their own uploads from YouTube Studio.

How it works

Your link is checked against a strict list of real YouTube hosts, the video ID is extracted, and the details are fetched from YouTube's official data services. The thumbnail our server delivers comes straight from YouTube's own image service. Nothing is scraped or extracted.

For developers — the API

This site runs on a standalone, versioned API that any website can call:

POST /api/v1/youtube/inspect
{"url": "https://www.youtube.com/watch?v=dQw4y9WgXcQ"}

GET  /api/v1/youtube/thumbnail/dQw4y9WgXcQ   (the thumbnail JPG)
GET  /api/v1/health

See the interactive API documentation for full schemas. Cross-origin use is enabled per-site by the operator via an allow-list — secrets are never exposed to browser code.

Privacy

URLs you inspect are sent to YouTube's official services to retrieve the video's public details. We don't require accounts, don't ask for any passwords or cookies, and don't sell data. Basic rate limiting uses your IP address in memory only.
